### 🔍 How to Preview Locally

#### Option 1: In VS Code / Antigravity IDE
- Open `README.md`.
- Press `Ctrl + Shift + V` (or `Cmd + Shift + V` on macOS) to open the Markdown Preview side-by-side.
- Ensure all icons, badges, and SVGs render cleanly.

#### Option 2: In Browser
- Open `assets/nafis-hero.svg` or `assets/nafis-footer.svg` directly in Chrome, Edge, or Firefox to view the animations and responsiveness.

### 🚀 How to Publish Using GitHub Desktop

1. Open **GitHub Desktop**.
2. Select your repository: `nafisquaisar` (the special profile repository `nafisquaisar/nafisquaisar`).
3. If this repository is in a separate folder, copy these files into your repository folder:
   - `README.md` (root directory)
   - `assets/nafis-hero.svg`
   - `assets/nafis-footer.svg`
   - `assets/icons/` (entire folder with vector icons)
4. In GitHub Desktop, check the **Changes** list in the left sidebar:
   - Confirm only `README.md` and the files in `assets/` are staged.
   - Review the diff to confirm no unintended files or personal phone numbers are included.
5. In the bottom-left **Summary** box, enter a commit message:
   ```text
   feat: upgrade profile README with real SVG vector icons and burgundy theme
   ```
6. Click **Commit to main** (or `master`).
7. Click **Push origin** in the top bar.
8. Visit `https://github.com/nafisquaisar` in your browser to view your live profile!
